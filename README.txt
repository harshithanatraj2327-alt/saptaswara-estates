SAPTASWARA ESTATES — WEBSITE STARTER

HOW TO RUN
1. Extract the ZIP folder.
2. Open the saptaswara-estates folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Keep all HTML files, style.css, script.js, and the assets folder together.

THE 7 PAGES
1. index.html — Home and property search
2. properties.html — Explore properties
3. about.html — About Saptaswara Estates
4. services.html — Property services
5. gallery.html — Image gallery
6. contact.html — Contact form
7. faq.html — Frequently asked questions

IMAGES
Your 9 uploaded images have been copied into assets/ and renamed descriptively. The gallery and page sections use these local image files.

IMPORTANT BEFORE GOING LIVE
- Listing names, prices, locations, dimensions and features are illustrative demo content, not verified live listings.
- The homepage search filters the sample property cards. It is not connected to a property database.
- The contact form is front-end demo only; it does not email or store submissions. Connect it to a backend or form service.
- Replace hello@saptaswaraestates.example with a real email address and add real phone/social links.
- The 24/7 support, verified property and best-price messaging should only be published if you can genuinely provide those services. Verify property ownership and documents before labeling any listing verified.
- Google Fonts requires an internet connection; fallback fonts are included.
- Confirm that you have permission to use each photo commercially before publishing.
